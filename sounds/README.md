Drop-in sound files (generated with ffmpeg, no licence restrictions). Replace any file with your own **same name** (.wav). Keep each under ~0.5 s for snappy feedback.
- move.wav: normal move
- capture.wav: capture
- castle.wav: castling
- check.wav: check
- error.wav: wrong move
- complete.wav: line finished

For .mp3/.ogg files, change the extension in `SOUNDS` / `fetch(\`sounds/${n}.wav\`)` in app.js.
